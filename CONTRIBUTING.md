# Contributing to react-native-kbz-pay

Thank you for your interest in contributing to `react-native-kbz-pay`! We welcome contributions from developers to help improve KBZ Pay mobile payment integration for the Myanmar developer community.

---

## 🛠️ Development Setup

1. Fork and clone the repository:
   ```bash
   git clone https://github.com/phonehtut/react-native-kbz-pay.git
   cd react-native-kbz-pay
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Build the library:
   ```bash
   npm run build
   ```

---

## 🚀 Making Changes

1. Create a feature branch:
   ```bash
   git checkout -b feature/my-feature-name
   ```

2. Make your improvements in `src/` (TypeScript API), `android/` (Java module), or `ios/` (Objective-C module).

3. Verify that the build succeeds without any errors:
   ```bash
   npm run build
   ```

4. Commit your changes following [Conventional Commits](https://www.conventionalcommits.org/):
   ```bash
   git commit -m "feat: add support for custom transaction metadata"
   ```

5. Push to your fork and submit a Pull Request.

---

## 🐛 Reporting Issues

If you encounter a bug or have a feature request:
1. Check the [Issues](https://github.com/phonehtut/react-native-kbz-pay/issues) tab to see if it has already been reported.
2. If not, open a new issue detailing:
   - React Native version & Expo SDK version (if applicable)
   - Platform (iOS or Android)
   - Expected vs Actual behavior
   - Code snippet or reproduction steps
